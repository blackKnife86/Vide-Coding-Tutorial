# AI 编程学习路线（Vibe Coding）

> 本目录根据程序员鱼皮「AI 编程学习路线」由GLM 5.2 + claude code xhigh整理，将 Vibe Coding 学习拆解为 **6 个阶段**，每个阶段一份详细教程，并附可参考的第三方教程链接。
>
> Vibe Coding 由 Andrej Karpathy 于 2025 年提出，核心理念是：用自然语言指挥 AI 生成、修改、部署代码，你专注于逻辑、架构与判断，把执行交给 AI。

|:---:|------|------|:---:|
| 一 | [AI 编程认知与基础准备](./阶段一_AI编程认知与基础准备.md) | 建立认知，掌握"看懂+验证+运行"的最小技术素养 | 1～2 周 |

## 🧭 学习心法

1. **你是驾驶员，不是乘客** —— AI 替你"打字"，但架构、需求、判断、验证仍是你的职责。
2. **完成 > 完美** —— 每个阶段都做出能跑、能上线的东西，正反馈驱动持续学习。
3. **上下文决定质量** —— 提示词与上下文工程的本质，是给 AI 最相关、最高质量的信息。
4. **Git 是安全网** —— 每个功能点 commit，AI 改崩了一键回退。
5. **安全不可外包** —— 上线前亲自过安全清单。

## 🚀 如何使用本路线

- **零基础**：从阶段一开始，严格按顺序推进，不要跳级。
- **有编程基础**：快速过阶段一、二，重点投入阶段三、四、五。
- **想直接做产品**：直奔阶段四 + 阶段六，遇到缺口回补对应阶段。

每份教程都包含：阶段目标 → 核心知识 → 实战/检查清单 → 推荐第三方资源 → 学习建议，并互相链接。
